# 公司盘（共享文件区）

这里是团队的公司盘（服务器目录 `~/desk-data/drive/`）：放公司共享文件——资料、模板、报表、交付物等，全员可读写。

## 怎么用

- 人用：工作台 → 左下角「设置」→「公司盘」：浏览文件夹、点文件名下载、点「上传文件」放入新文件。
- Windows 侧访问：资源管理器地址栏输入 `\\wsl.localhost\Ubuntu\home\yangc\desk-data\drive`（拖文件也可以）。
- Agent：会话里可以直接读写这个目录（每个工作区的 AGENTS.md 已提示它）。

## 边界（v1，2026-09-19）

- 全员可读写（1–3 人内部试用）；单文件上传上限 50MB。
- 暂不支持在界面里删除 / 移动 / 改名（在 Windows 资源管理器里操作即可；界面版后续再加）。
- 只在本机 / 局域网使用，未对外开放。
