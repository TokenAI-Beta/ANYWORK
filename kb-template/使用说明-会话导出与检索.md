# 工作台使用说明：会话导出 & 历史检索

## 导出会话（存档 / 交接 / 留证）

- 在工作台里打开一个会话 → 右上角「Session log」按钮（或输入 `/export`）→ 浏览器下载 ZIP（含本会话、子会话、附件）。
- 用途：把重要讨论存档、交接给同事、留底备查。

## 让 agent 搜历史会话

- 直接说：'在过去的会话里搜一下 XXX' —— agent 会调用检索工具（session_search）。
- 范围：**只在你自己工作区内跨会话搜索**（别人搜不到你的，你也搜不到别人的）。
- 适合找：'上次那个价格怎么定的'、'之前讨论过的流程'。

（检索由管理员开启；索引在首次搜索时自动构建并落盘，日常无需维护。）
