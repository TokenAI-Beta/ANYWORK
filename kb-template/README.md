# 团队知识库（企业知识库）

这里是 DSH-ANYWORK 的共享知识库（服务器目录 `~/desk-data/kb/`）。成员在工作台「设置 → 知识库」里直接查询；各实例里的 agent 也可以直接读这个目录。

## 怎么放文件

- 直接把文档丢进 `收件箱/` 或按主题建子目录（支持 .md / .txt / .csv / .json / .yml 等文本格式）。
- Windows 侧访问：资源管理器地址栏输入 `\\wsl.localhost\Ubuntu\home\yangc\desk-data\kb`。
- 检索是**实时**的：文件放进去，下一次查询就能搜到，无需导入。

## 怎么查

1. 人查：工作台 → 左下角「设置」→「知识库」→ 输入关键词 → 查询。
2. Agent 查：在会话里直接让 agent 检索 `~/desk-data/kb`（每个工作区的 AGENTS.md 已提示它）。

## 版本与边界（v1，2026-09-19）

- 检索方式：子串全文匹配（零依赖，小规模下够快够准）；暂不支持向量 / 语义检索。
- 权限：v1 全员可读（1–3 人内部试用）；后续按角色过滤（如管理层文档）。
- 更新：v1 手动放入；后续可接「会话沉淀 / 自动同步」。
