# 团队报告写作规范

写任何报告、方案、汇报、总结时，遵循以下规范：

1. **结论先行**：开头先给结论 / 建议（一句话讲清），不要慢慢铺垫。
2. **数据支撑**：关键数字必须标注来源与口径；口径不明就写明"口径待确认"。
3. **不确定用区间**：对测算值给出区间（如 3–5 万），并标注假设，写明"这是假设，不是事实"。
4. **严禁编造**：找不到的数据写"数据缺口"，绝不用看起来合理的假数；财务数据尤其禁止推测。
5. **结构**：每章开头给 3–5 条核心结论；结尾附「数据缺口清单」与「下一步建议」。
6. **术语**：专业名词首次出现时用一句话解释。
7. **盲区提示**：主动补充"对方可能没想到的点"（风险、依赖、前置条件）。
8. **语气**：正式、克制；对外文件不出现内部角色 / 发起人信息。
