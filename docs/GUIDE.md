## 0. 快速开始

**登录**：浏览器打开工作台地址 → 输入用户名 / 密码 → 进入自己的工作区（dsh 会话界面）。

**界面导航**：
- 左侧栏上方：`+ 新会话`、工作区与会话列表；
- 左侧栏左下角：**🧑‍💼 助理** / **🧩 技能·连接器** / **⚡ 自动化** / **📢 公告** / **设置**（8 个设置页）。

**桌面端（可选）**：
1. 本机桌面「**DSH 团队工作台（应用）**」快捷方式 —— 独立窗口，双击即用；
2. 浏览器地址栏「**安装应用**」（PWA，适合 https/localhost；局域网 http 环境用第 1 种）；
3. 转发给成员：`%LOCALAPPDATA%\desk-anywork\desk-app\DSH工作台-应用模式（成员可转发）.bat`。

> 桌面端只是给同一网页套壳 —— **网页端更新，桌面端自动是最新的**。

**手机**：同一 Wi-Fi 下浏览器直接打开工作台地址即可。

## 1. 工作台基本操作

| 操作 | 怎么做 |
|---|---|
| 开新会话 | 侧栏 `+ 新会话`（可选「Agent 预设」角色，默认 `team-assistant`） |
| 后台任务 / 子代理 | 直接对 agent 说，例如「后台跑 xxx」「派个子代理做 yyy」；会话头部有任务条，点开看输出 |
| 会话导出（存档） | 会话头「Session log / 导出」→ 下载 ZIP（含全部消息）；**重要会话删除前先导出** |
| 跨会话检索 | 对 agent 说「搜一下我们之前关于 xxx 的讨论」——agent 会用 `session_search` 在你有权限的会话里搜 |
| 会话删除 | 见 [§2.3 会话管理](#23-会话管理删除管理员批准制) |

## 2. 设置页（8 个）

### 2.1 工作台用量

- **入口**：设置 → 工作台用量（右下角也有常驻「用量」胶囊）。
- **看什么**：本月 token 用量、费用、按天趋势。
- **口径**：按 DeepSeek 官方**峰谷价**计价 —— 高峰 = 北京时间周一~五 9:00–12:00 / 14:00–18:00，其余时段（含整个周末）半价；走外部通道的调用按该通道的价目表计费。
- **预算**：每月用量到预算 **80% / 100%** 时自动推管理员一条告警（每档每月一次）。

### 2.2 任务板

- **入口**：设置 → 任务板（全员可见）。
- **怎么用**：
  1. 「新建任务」：标题 + 备注 + 可指派成员；
  2. 无主任务**任何成员可「接领」**（把自己设为负责人）；
  3. 状态流转（进行中 / 完成 / 删除）。
- **权限**：管理员、任务的发起人、当前负责人可修改/删除；接领是例外（人人可接无主任务）。
- **用途**：团队事项留痕与交接，不替代会话记录。

### 2.3 会话管理（删除·管理员批准制）

- **入口**：设置 → 会话管理（全员可见）。
- **成员怎么删会话**：在「我的会话」里找到目标 → **申请删除** → 变成 ⏳ 待管理员确认（可「撤销」）；管理员会收到一条通知，批准后生效。下方「我的申请」随时看审批状态。
- **管理员怎么删**：
  - 「待审批」里 **批准删除 / 驳回**（批准=立即执行）；
  - 「成员会话」：下拉选成员 → 加载会话 → 对任意一条**直接删除**；
  - 自己的会话在「我的会话」行上直接有「删除」。
- **注意**：
  - **删除不可恢复**（比"归档"彻底）——重要会话先按 [§1](#1-工作台基本操作) 导出 ZIP 存档；
  - 执行删除时，对应实例会**自动重启约 5~10 秒**（页面闪断一下属正常，会自动恢复）；
  - 已归档的会话也会一并被清除。

### 2.4 知识库

- **入口**：设置 → 知识库（全员）；侧栏「技能·连接器」可快捷查看。
- **怎么用**：
  - 浏览 / 搜索：关键词全文检索团队共享知识；
  - **沉淀一条**：设置 → 知识库 → 底部「沉淀」表单（标题 + 正文，作者自动记录）；
  - 也可让 agent 沉淀：对 agent 说「把结论沉淀到知识库」→ 它用 `desk-kb` 命令写入。
- **注意**：知识库全员共享；删除笔记仅管理员（`kb/rm`）。

### 2.5 公司盘

- **入口**：设置 → 公司盘（全员）。
- **怎么用**：浏览目录 → 点击下载；「上传」选择文件（单文件 ≤ 50MB）→ 全员可见。
- **用途**：团队大文件交换区（表格、图纸、文档…）。

### 2.6 成员管理（管理员）

- **入口**：设置 → 成员管理（仅管理员；成员打开会看到权限提示）。
- **三块内容**：
  1. **成员**：列表含在线状态、最后登录、近 7 日用量趋势、月预算；「新建成员」返回**虚拟钥匙（只显示一次，请当场转交）**；「删除成员」数据留档。
  2. **模型通道**：填写名称 / Base URL / Key / 模型列表（可带价目表）→ 网关按**模型名**分流到该通道；可随时开关或删除。未命中的模型走「团队共用上游」。
  3. **团队共用上游（默认）**：显示当前真 key（打码，如 `sk-ec****2418`）；粘贴新 key → 「更新 Key」→ 自动写盘并重启网关（**约 5~10 秒内工作台短暂打不开**，正常）。
- **注意**：若服务器以环境变量提供真 key，此处为只读（以实际显示为准）。

### 2.7 通知

- **入口**：设置 → 通知（全员可看记录；通道管理仅管理员）。
- **通道（4 种）**：webhook / 微信 / Telegram / WhatsApp —— 添加时选类型、按「目标格式」填写、可随时启用/停用、删除、「发送测试」验证。开通步骤见 [§5.1](#51-通知通道开通指南)。
- **提醒列表**：当前所有定时提醒（新增方式见 [§5.2](#52-定时提醒3-种姿势)；删除在此页或让管理员处理）。
- **通知记录**：最近发送结果（成功/失败原因），排障先看这里。

### 2.8 运维（管理员）

- **入口**：设置 → 运维（仅管理员）。
- **看什么**：各服务（systemd 单元）运行状态、门户/网关/各实例端口探活、备份目录与最近备份时间、磁盘占用。
- **用途**：排障第一屏 ——「哪里不对劲」先看这里。

## 3. 侧栏模块（4 个）

### 3.1 助理（🧑‍💼）

- **看什么**：团队全部 **Agent 预设（角色）** —— 名称、描述、是否接 Codex。
- **怎么用**：新会话时选对应的「Agent 预设」即以该角色开工（默认 `team-assistant`）。
- **维护**（管理员/自用）：见 [§4.2](#42-agent-预设角色)。

### 3.2 技能·连接器（🧩）

- **技能**：列出共享技能库全部技能（名称 + 描述），点开可看全文。
- **连接器**：模型网关、通知通道、Codex、GitHub、知识库/公司盘、技能与预设的**状态一览**（正常/未配置）。
- **怎么用**：对 agent 直接说「用 `xxx` 技能做 …」即可；agent 也会按技能描述自动匹配。

### 3.3 自动化（⚡）

- **看什么**：定时提醒列表（到点、内容、谁设的）+ 最近自动化记录。
- **怎么新增**：见 [§5.2](#52-定时提醒3-种姿势)。

### 3.4 公告板（📢）

- **看什么**：团队公告（有新公告时按钮带红点，打开即清零）。
- **成员**：面板内可提交「意见反馈」。
- **管理员**：在面板内发布 / 删除公告，并查看全部反馈。

## 4. 团队能力（agent 侧）

### 4.1 团队技能库

- **位置**：服务器共享区 `~/desk-data/skills/`。
- **新增一个技能**：建目录 `<kebab-name>/SKILL.md`，frontmatter 填 `name` + `description` → **保存即被发现**（无需重启，三个实例同时可用）。
- **工作区私有技能**：放自己工作区的 `.dsh/skills/`（只对自己生效，优先级更高）。
- **模板**：仓库 [`skills-template/`](../skills-template/)。

### 4.2 Agent 预设（角色）

- **位置**：`~/desk-data/presets/<id>/`（`preset.yml` + `agent.cordis.yml`）；默认 `team-assistant`。
- **新增角色**：拷贝官方 `standard` 模板改 `preset.yml` → 用 `scripts/apply-team-persona.mjs` 应用人格 → 新会话即可选。
- **模板**：仓库 [`presets-template/`](../presets-template/)。

### 4.3 Codex 子代理与并行工作流

- **单发**：对 agent 说「用 `subagent_codex` 派给 Codex：<任务>」；
- **并行**：说「用 workflow 并行跑这两路：<A>、<B>」；
- **worktree 并行**：装了 `codex-parallel-worktrees` 技能，对 agent 说「按这个技能开两个 worktree 并行做」即可。
- **注意**：Codex 的额度走它自己的账号，**不进入团队用量账单**。

### 4.4 团队 Soul / 工作区规范

- **行为准则**：`~/desk-data/soul/SOUL.md`（软链到各实例）—— 改一处，全员**新会话**生效（运行中的会话会在下一条消息折入）。
- **工作区规范**：你工作区根的 `AGENTS.md`（团队通用规范 + 可加自己的）。
- **模板**：仓库 [`soul-template/`](../soul-template/)。

### 4.5 安全闸门

- **是什么**：20 条危险命令策略挂在所有会话上 —— `deny`（直接拦截，并推一条通知给管理员）/ `ask`（会话里弹审批）/ 放行。
- **规则**：`~/desk-data/hooks/rules.json`（改完下一次工具调用即生效）。
- **实测**：`rm -rf` 等危险命令会被拦截并给出「团队安全闸门拦截…」提示。

## 5. 通知与提醒

### 5.1 通知通道开通指南

在 **设置 → 通知 → 添加通道** 里选类型，按下面格式填「目标」：

| 通道 | 目标格式 | 开通步骤 |
|---|---|---|
| webhook | `https://你的服务/receive` | 你的接收端会收到 `POST {title, text, source, at}` JSON |
| 微信 | `weixin` | 由服务器上的 Hermes 提供（已内置，无需配置） |
| Telegram | `bot_token\|chat_id` | ① Telegram 找 **@BotFather** → `/newbot` 拿 **bot_token**；② 给你的新 bot 发任意一条消息；③ 浏览器开 `https://api.telegram.org/bot<token>/getUpdates` 找到 `chat.id`；④ 填入 `token\|chat_id` |
| WhatsApp | 三选一（见下） | CallMeBot / green-api / UltraMsg |

**WhatsApp 三种接法**：
- **CallMeBot（个人免费、最简单）**：用要收消息的手机 WhatsApp 给 `+34 644 51 95 23` 发 `I allow callmebot to send me messages` → 收到 **apikey** → 目标填 `callmebot|<apikey>|+86你的手机号`；
- **green-api**：在 console.green-api.com 注册 → 建实例并扫码 → 目标填 `greenapi|<idInstance>|<apiTokenInstance>|<接收号码>`；
- **UltraMsg**：在 ultramsg.com 注册并建实例 → 目标填 `ultramsg|<instanceId>|<token>|<接收号码>`。

> 配好后点「**发送测试**」验证；多个通道会**同时收到**同一条通知（按启用状态）。

### 5.2 定时提醒（3 种姿势）

1. **对 agent 说**：「30 分钟后提醒我 …」「明天 9 点提醒我带材料」→ agent 用 `desk-remind` 落提醒；
2. **面板/设置**：⚡ 自动化面板或 设置 → 通知 里查看与删除（新增走第 1 种或让 agent 加）；
3. **命令行（agent 侧）**：`desk-remind "10:00" "开晨会"`。

**时间格式**：`10:00`（已过则顺延到明天）· `明天 09:00` · `09-22 10:00` · `+30m` · `+2h`。
**到点**：自动走**所有已启用通知通道**推送；`desk-remind list` / `desk-remind rm <id>` 管理。

### 5.3 agent 侧命令速查（共享区 `~/desk-data/bin/`，所有实例可用）

| 命令 | 用途 |
|---|---|
| `desk-notify "标题" "正文"` | 主动推一条通知（走所有启用通道） |
| `desk-remind …` | 定时提醒（见上） |
| `desk-kb "标题" "正文"` / `desk-kb list` / `desk-kb search 词` | 知识库沉淀 / 列表 / 搜索 |

## 6. 界面与客户端

### 6.1 玻璃主题（Aqua，可选）

- **开关**：设置 → 插件 → 插件配置 →「**玻璃主题**」→ 开启；关掉即**完整还原**原生界面。
- **特性**：磨砂玻璃侧栏 + 流体/壁纸背景（可调模糊度、磨砂度、背景亮度、粒子等）。
- **注意**：这是**每人各自的浏览器本地偏好**（不影响他人）；升级 dsh 版本后需同步更新该插件版本（见仓库 `scripts/install-transparent-ui.sh`）。

### 6.2 桌面端

见 [§0 快速开始](#0-快速开始) 的三种用法。要点：桌面端=同一网页的壳，**网页更新即桌面最新**。

## 7. 模型钥匙与费用

### 7.1 三把钥匙，各管各的

| 钥匙 | 在哪管 | 谁能改 |
|---|---|---|
| **团队共用真 key**（默认上游） | 设置 → 成员管理 → 「团队共用上游（默认）」 | 管理员 |
| **外部通道 key**（按模型分流） | 设置 → 成员管理 → 「模型通道」 | 管理员 |
| **成员自己的钥匙** | 设置 → 模型（Models 页，可编辑/替换） | 成员本人 |

- 成员默认使用团队**虚拟钥匙**（`sk-desk-…`，自动播种，无需关心）；
- 成员想换成**自己的真 key**：在 设置 → 模型 里替换，并**同时把 Base URL 改为 `https://api.deepseek.com`**（否则请求仍打到团队网关会被拒）。

### 7.2 费用口径

- 峰谷价（高峰 = 周一~五 9:00–12:00 / 14:00–18:00 北京时间，其余半价）；
- 外部通道按通道价目表计；
- 预算告警：80% / 100% 每档每月各推一次给管理员。
